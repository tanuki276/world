# Nucleus End（Web版）

2027年1月1日発売・価格2円。音楽／デザイン／マップ全て個人制作の探索ゲーム。

北方の孤島シェネタプラ島。数百年に一度すべてを焼く天災「アスラティ雷雨」が近づいている。
地上の民は信じている。天空神殿最奥の『原子核』を破壊すれば、気候を制御して世界を救えるのだと。

## 遊び方

静的ファイルとして配信すればそのまま動く（例: `python3 -m http.server` でこのフォルダを開く）。

- WASD: 移動 / マウス: 視点（クリックでポインターロック）
- E: 村人に話しかける / 会話を進める
- T: アスラティ雷雨を呼ぶ
- iPad 等のタッチ端末: 左スティックで移動、右側ドラッグで視点、「話す」「雷雨」ボタン

南の海岸に降り立ち、シヴェシュッタ村で村人全員の話を聞いてから、ユヴァシレフ草原を北へ抜けるのが最初の旅程。

## 構成

- `index.html` — 画面とUI
- `src/` — ゲーム本体（地域は南／草原／北を動的にロード・アンロード）
- `assets/` — Poly Haven（CC0）の実テクスチャと実モデル。出典一覧は `ASSETS.md`
- `lib/` — Three.js r160（vendored）

## 注意

このリポジトリにはまずコード一式が入っている。`assets/` 配下のバイナリ（.glb / .bin / .jpg）が揃うまでは、モデルが読み込めずゲームは起動しない。
